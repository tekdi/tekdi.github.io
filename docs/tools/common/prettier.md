# Prettier

## Prettier Config

Use below config for prettier, it works well with recommended ESLint configs.
Add it in `.prettierrc` file in your repo root.

```
{
  "singleQuote": true,
  "trailingComma": "all",
  "useTabs": true,
  "endOfLine": "lf"
}
```
